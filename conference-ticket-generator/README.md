## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as melhores práticas e ferramentas modernas do ecossistema web:

- **Next.js (App Router)** - Framework React para renderização e rotas.
- **TypeScript** - Tipagem estática para maior segurança e escalabilidade do código.
- **Tailwind CSS** - Estilização moderna e utilitária focada em design responsivo.
- **React Hooks (`useState`)** - Gestão de estados globais do formulário e validações.

---

## ✨ Funcionalidades

- **Formulário Dinâmico:** Captura de nome, nome de utilizador do GitHub e upload de imagem de avatar.
- **Pré-visualização de Imagem:** Conversão de arquivos locais em URLs temporárias (`URL.createObjectURL`) para visualização instantânea.
- **Validação de Campos:** Verificação de preenchimento obrigatório antes da emissão do bilhete.
- **Renderização Condicional:** Transição fluida entre o ecrã do formulário e o ecrã de sucesso com o bilhete personalizado.
- **Design Responsivo:** Totalmente adaptado para dispositivos móveis, tablets e computadores de secretária.

## 💻 Como Executar o Projeto

Certifica-te de que tens o [Node.js](https://nodejs.org/) instalado na tua máquina.

1. **Clonar o repositório:**

   git clone https://github.com/FelipeGdasilva/frontend-mentor-challenge.git

2. **Aceder à pasta do projeto:**

   cd frontend-mentor-challenge/conference-ticket-generator

3. **Instalar as dependências:**

   npm install

4. **Executar o servidor de desenvolvimento:**

   npm run dev

5. **Abrir no navegador:**

   Acede a http://localhost:3000 para veres a aplicação a funcionar.
